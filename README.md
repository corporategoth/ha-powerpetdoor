A [Home Assistant][homeassistant] integration for control and monitoring of the
[Power Pet Door][powerpetdoor] made by [High Tech Pet][hitecpet].

Talks to the door directly over your own network — no cloud, no account, no
polling. The door pushes changes as they happen.

## Install

This integration is in the **HACS default repository** — you no longer need to
add it as a custom repository.

1. Open **HACS** in Home Assistant.
2. Search for **Power Pet Door** and click **Download**.
3. Restart Home Assistant.
4. **Settings → Devices & services → Add integration**, search for
   **Power Pet Door**, and enter your door's IP address.

[![Open your Home Assistant instance and open a repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=corporategoth&repository=ha-powerpetdoor&category=integration)
[![Open your Home Assistant instance and start setting up a new integration.](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=powerpetdoor)

Full details, including manual installation and the Lovelace card, are in
**[docs/installation.md](docs/installation.md)**.

### Supported versions

The supported grid is **measured, not declared** — Home Assistant's stated
Python requirement is only a floor, and an old Home Assistant also pins old
dependencies that will not build on a new interpreter. So each interpreter has
both an oldest and a newest Home Assistant that actually works:

| Python | Oldest Home Assistant | Newest Home Assistant |
|--------|----------------------|-----------------------|
| 3.13   | 2025.4.0             | 2026.2.3              |
| 3.14   | 2025.11.0            | 2026.8.3              |

**Minimum Home Assistant: 2025.4.0.** Python 3.11 and 3.12 are not supported:
no Home Assistant that this integration passes its test suite against will run
on them.

That table is what the suite actually *passes* on, not what merely installs —
the difference is large. A resolve-only probe claimed support back to HA
2024.6.0 on Python 3.12; running the tests against each pair showed the
integration does not work there at all.

CI tests every pair in that table. It is regenerated by
`scripts/ha_matrix.py`, which probes the combinations for real — see
[docs/development.md](docs/development.md#supported-versions).

## What you get

One device with 29 entities. The headlines:

| Entity | What it does |
|---|---|
| `cover.<name>_door` | Open (and hold) or close the flap |
| `switch.<name>_power` | The door's motor power |
| `switch.<name>_inside_sensor` / `_outside_sensor` | Enable each pet sensor |
| `switch.<name>_connection` | Disconnect Home Assistant so the phone app can use the door |
| `binary_sensor.<name>_inside_schedule` / `_outside_schedule` | Whether a schedule window is open now |
| `sensor.<name>_battery` | Battery level |
| `button.<name>_cycle` / `_toggle` | One-shot commands the cover cannot express |

Plus configuration, diagnostic and statistics entities — several disabled by
default. The complete list, and what each one means, is in
**[docs/entities.md](docs/entities.md)**.

> **Note:** The Power Pet Door only supports a single network connection at a
> time. To use the official mobile app, turn the `Connection` switch off
> first. If Home Assistant cannot connect, make sure the mobile app is closed.

## Schedules

The door can enable each sensor on a weekly schedule. This integration ships a
Lovelace card for viewing and editing it by dragging:

![Schedule card](images/petdoor-card.png)

Schedules can also be set from an automation with the
`powerpetdoor.set_schedule` action. See **[docs/schedules.md](docs/schedules.md)**.

## How it works

All protocol handling lives in **[pypowerpetdoor][pypowerpetdoor]**, a
standalone library. This repository is the Home Assistant integration on top
of it — entities, the config flow, and the schedule card. To talk to a Power
Pet Door from something that is not Home Assistant, use the library directly;
it also ships a full door simulator.
